# Model Documentation

This directory documents the frozen GraphMate model family and related training/evaluation notes.

Start with:

- [model_family.md](model_family.md) for the high-level family map.
- [graph_representation.md](graph_representation.md) for node, edge, and global features.
- [experimental_protocol.md](experimental_protocol.md) for experiment conventions.
- [model_a3.md](model_a3.md), [model_b.md](model_b.md), and [model_a4.md](model_a4.md) for the main final comparisons.

Detailed historical notes for Model A variants live under [model_a/](model_a/). Model A1 is an inference mode over Model A rather than an independent checkpoint.
