# Official Training Configurations

This directory contains the frozen official training configurations for GraphMate models A, A2, A3, B, and A4.

These files document the training setup used for the published frozen checkpoints. They do not guarantee bit-for-bit reproduction of checkpoint bytes on a new machine. GPU kernels, CUDA/PyTorch/PyG versions, nondeterministic operations, and environment differences can change the selected best epoch and final weights.

## Files

| Config | Model | Frozen checkpoint | Role |
| --- | --- | --- | --- |
| `model_a.json` | A | `checkpoints/model_a/best.pt` | Global-vocabulary no-timing GAT baseline |
| `model_a2.json` | A2 | `checkpoints/model_a2/best.pt` | Legal-masked global-vocabulary GAT |
| `model_a3.json` | A3 | `checkpoints/model_a3/best.pt` | No-timing legal-move candidate scorer |
| `model_b.json` | B | `checkpoints/model_b/best.pt` | Timing-aware controlled A3 variant |
| `model_a4.json` | A4 | `checkpoints/model_a4/best.pt` | Frozen A3 Top-5 post-move GNN reranker |

A1 is absent by design. It is an inference-only best-legal mode over Model A, not an independently trained model.

## Directory Semantics

- `checkpoints/`: frozen trained model states used for published results.
- `configs/`: frozen training configurations used to reproduce the official model setups.
- `artifacts/retraining/`: ignored local outputs from new user retraining runs.
- `resources/`: small canonical runtime resources such as the move vocabulary.

## Inspect A Config

```bash
./venv/bin/python -m src.cli.training.train_official --model a3 --dry-run
```

Use `--model a`, `--model a2`, `--model a3`, `--model b`, or `--model a4`. You can also pass `--config configs/model_a3.json`.

Dry-run resolves and validates the config, prints required input paths, reports missing files, chooses a safe retraining output path, and does not train.

## Retrain From An Official Setup

```bash
./venv/bin/python -m src.cli.training.train_official --model a3
```

Retraining writes to `artifacts/retraining/<model>/<timestamp>/` by default and refuses to use canonical `checkpoints/model_*/` directories as output. The tracked checkpoint files remain immutable reference artifacts.

A4 depends on the frozen A3 checkpoint for Top-5 retrieval and does not retrain A3 automatically. Model B requires the timing-prepared PyG dataset generated by the frozen synthetic timing protocol.

## Pretrained Checkpoints

Use `checkpoints/` when you want the published pretrained models. Use `configs/` when you want to inspect or rerun the training setup that produced the published model family.
