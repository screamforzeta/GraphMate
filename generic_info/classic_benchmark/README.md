# Classic Benchmark Documentation

This directory documents the external YACPDB classic-composition benchmark used for GraphMate generalization testing.

Core documents:

- [heldout_classic_dataset.md](heldout_classic_dataset.md): dataset role and structure.
- [classic_benchmark_methodology.md](classic_benchmark_methodology.md): benchmark methodology.
- [classic_evaluation_protocol.md](classic_evaluation_protocol.md): evaluation protocol.
- [yacpdb/yacpdb_methodology.md](yacpdb/yacpdb_methodology.md): YACPDB source methodology.
- [popeye/popeye_methodology.md](popeye/popeye_methodology.md): independent Popeye verification methodology.

The frozen benchmark contains 200 directmate compositions, 20 per mate depth from #1 through #10. Model B is not evaluated on this benchmark because timing inputs are unavailable.
